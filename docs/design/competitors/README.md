# Competitor reference: ValBuddy / Daily Val

Screenshots: `valbuddy/vb_*.jpg` (App Store, v2.x, 2026), contact sheet `valbuddy/sheet.jpg`.
Daily Val is no longer on the App Store and its site (dailyval.shop) is down; reference
material has to come from the owner's iPhone (`dailyval/`).

## ValBuddy visual language (what makes it look better than ValVN today)

- **True black background** (#000) with near-black cards (~#121212 / #1C1C1E), hairline
  separators, very little chrome. Feels native iOS (SF Pro-like bold titles), dense but calm.
- **Large left-aligned bold title** per tab ("Store", "Collection"…) in a plain bold sans —
  not a display face. Small uppercase grey section labels ("ACCOUNTS (5/5)", "PREFERENCES").
- **Floating capsule tab bar**: rounded pill detached from the bottom edge, translucent dark
  glass, 5 icons with small labels, the active item sits in a red-tinted pill with red icon +
  label.
- **Segmented filters as pills**: active = solid red pill with white text, inactive = dark grey
  pill; used for Store segments (Daily / Accessories / Bundles), Match History modes, Your Team /
  Enemy Team.
- **Wallet**: one full-width dark pill with three centered currency icon + amount pairs.
- **Store cards**: full-width, ~2.2:1, dark background tinted by the content tier colour,
  large centred skin render, bottom row = tier icon + skin name (left), VP icon + price
  (right). Small "Resets in 11:54:37" line with clock icon under the segments.
- **Grouped lists** (Settings, Collection "Loadout" / "Browse Collection"): rounded dark
  containers, each row = red outline icon + title + trailing value in grey + chevron.
- **Account rows**: avatar (player card), name/meta, rank icon, red trash button in a round
  red-tinted circle; active account marked by a red bar on the left edge.
- **Game details**: big rounded map splash header, map name + mode, status chip ("In Progress"
  green / "Agent Select" amber) with a refresh ring, red pill team toggle, roster rows with agent
  portrait, name, rank icon + rank name.
- **Agent select**: 5-column grid of agent portraits with names, hint "Tap to hover an agent,
  hold to lock.", red outlined "Quit Match" button at the bottom.
- **Battle Pass**: compact card "Season 2026 // Act III", Level 46 / 55, thin red progress bars,
  "View All Rewards 46/55 unlocked" row, Weekly Missions with circle checkmarks, strike-through
  completed missions, red XP reward, countdown with clock icon.
- **Profile**: wide player-card banner, level + XP thin bar, Rank card with Current / Peak side
  by side (big rank icons), Current Game card with countdown ring, Match History mode pills,
  match cards = large map image with overlay "Icebox 4 - 5 Defeat, K/D/A 5/9/1 · 18h ago".

## ValVN direction

Adopt: true-black dark theme option (default dark = near-black, keep navy only as accent
surfaces), floating glass capsule tab bar, red pill segments, image-forward full-width store
cards with tier-tinted backgrounds, grouped rows with red outline icons, thin progress bars,
large map-art headers. Beat it with: Vietnamese copy, community tab, richer stats (win rate,
RR/day), wishlist/value, video previews, smoother motion.
