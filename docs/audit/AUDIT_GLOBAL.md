# ValVN global-readiness audit (read-only)

**Baseline:** branch `claude/jolly-hawking-23o2j8`, HEAD `009d1c1`. Working tree has only untracked `dist/` and screenshots; `.claude/worktrees/**` ignored. No files were modified.

**Paths:** every path is under `D:\ValVN\`, so `lib/x.dart` means `D:\ValVN\lib\x.dart`.

**Method:** ripgrep and grep counts, a cmap parse of the bundled fonts, `material_ui-1.4.0` source, and code reading. Counts are snapshots of a fast-moving tree.

**Severity:**
- critical: blocks or misleads non-Vietnamese users by default, or is a structural blocker for the i18n plan.
- high: major core-flow or compliance gap.
- medium: degraded but usable.
- low: polish, docs, or unverified edge.

**Effort (agent-time):** S is up to 0.5 day, M is 1 to 3 days, L is over 3 days.

**Dependencies:** `I18N Wn` is a wave in `docs/design/I18N.md`, `COUNTRIES Pn` is a phase in `docs/design/COUNTRIES.md`, `DEVICES` is `docs/design/DEVICES.md`, and `NEW` means no plan covers it.

## 1. Executive summary

**Global readiness: 3/10.** The design intent is about 8/10, but the shipped implementation is about 2/10.

- **Not merged.** There is no `l10n.yaml`, no `lib/l10n/`, and no `flutter: generate`. All three plans are documents only.
- **The UI and data are Vietnamese-only:**
  - UI locale is pinned to `vi` (`lib/app/app.dart:81-83`).
  - The Riot login page is forced to `ui_locales=vi` (`lib/core/config/app_constants.dart:10`).
  - The default content language is `vi-VN`.
  - Riot status notices, notifications, legal texts, the iOS purpose string and the community server messages are Vietnamese.
  - The only user-visible literal outside the strings and legal files is `lib/features/wishlist/ui/widgets/wishlist_notification_toggle.dart:90`.
- **What is already right:**
  - Game logic is keyed by ids.
  - Schedules use UTC and display uses the device time zone.
  - Search folding is language-independent.
  - The content cache is per language.
  - The community backend is country/region/language aware.
  - The Home tab is RTL-aware.

**Where the existing plans are wrong or incomplete:**
- `I18N.md` §2.1 says there are no fragments outside the strings files. There are about 27 sites (GL-10).
- `I18N.md` §2.2 says there are no persisted labels. The default preset name is persisted (GL-38).
- `I18N.md` §8.1 plans a `dirIcon` helper for 21 icons. Most icons already mirror; only `Icons.logout` does not (GL-16).
- `DEVICES.md` §1.8 claims `logout` mirrors, which is false for `material_ui` 1.4.0.
- `COUNTRIES.md` Q14 calls the 18 `language` codes unverified, but `docs/research/content-api.md:32,65` already lists them as accepted.
- No plan covers server-side i18n, DST day math, `normalizeTier`, or client versus server text-length semantics.

## 3. Already correct: do not break

- **Id-keyed content logic.** `ContentTier.shortName` switches on `devName` (`lib/core/content/models/cosmetic_models.dart:376`), `Currency.label` on uuid (`:430`), `roleNames` on role uuid (`lib/core/l10n/content_strings.dart:110-115`), and queue and map filters on ids.
- **Language-independent search.** `lib/core/util/search_text.dart:60,115,126` (`foldForSearch`, `compareNames`, `SearchIndex`), used by friends, collection, wishlist and countries (`lib/core/xmpp/friends.dart:90-95`).
- **UTC and device-time discipline.**
  - `lib/features/wishlist/background/wishlist_check_state.dart:32-41` and `lib/features/settings/ui/sections/notifications_section.dart:24-27` use UTC.
  - `lib/features/store/providers/store_reset_reminder.dart:55-57` uses API absolute instants.
  - XMPP timestamps are parsed as UTC (`lib/core/xmpp/xmpp_parsers.dart:43-61`).
  - Displays use `toLocal()` device time.
  - Server times are ISO UTC (`server/community/src/context.ts:206`).
- **Content cache.** Keyed by manifest, language and schema (`lib/core/content/content_repository.dart:22-25,79-86`), with a per-language miss throttle and parsing in an isolate.
- **Unicode-safe validation.**
  - Riot ID input uses `\p{L}\p{N}` and counts runes (`lib/features/social/data/riot_id_input.dart:3,13-18`).
  - The server counts code points after NFC (`server/community/src/validate.ts:50-54,101-104`).
  - The login fill script selects inputs by name and type, not by label (`lib/core/accounts/login_note.dart:118-121`).
- **Community backend.**
  - v3 scopes with `appliedScope`, and country taken from Riot server-side (`server/community/src/routes/auth.ts:57`).
  - 17 language codes with variant normalization (`server/community/src/geo/languages.ts:34-46`).
  - Per-script moderation lists (`server/community/src/moderation/filter.ts:625-705`).
  - ML Kit mapping for all 17 codes (`lib/features/community/data/community_translator.dart:47-66`).
  - The consent sheet says the country is public (`lib/features/community/community_strings.dart:574-575`).
- **Home feature is RTL-aware.** Home has only symmetric insets and directional widgets, plus an RTL test (`test/features/home/ui/home_adaptive_a11y_test.dart:171-179`).
